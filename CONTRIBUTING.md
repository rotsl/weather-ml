# Contributing to weather-ml

Thank you for your interest in contributing!

This project is an automated machine learning system for weather forecasting.
Contributions are welcome in the areas of:

- Data processing
- Feature engineering
- Model development
- Monitoring
- Documentation
- Testing

---

## 🛠 Development Setup

1. Fork the repository
2. Clone your fork
3. Create a virtual environment
4. Install dependencies:
    ```bash
    pip install -r requirements.txt
     ```
5.	Create .env for local testing

---

## 📌 Workflow
1.	Create a feature branch:
    
    ```bash
     git checkout -b feature/my-feature
    ```

2.	Make changes
3.	Run tests / scripts locally
4.	Commit with clear messages
5.	Open a Pull Request

---

## 📋 Code Standards
	•	Use Python 3.9+
	•	Follow PEP8
	•	Add docstrings
	•	Avoid hardcoded secrets
	•	Do not commit .env

---

## 🧪 Testing

Before submitting:
	•	Run training locally if applicable
	•	Verify dashboard export
	•	Check workflow compatibility

---

## 🤝 Review Process

All pull requests are reviewed for:
	•	Correctness
	•	Reproducibility
	•	Security
	•	Resource usage
	•	Documentation quality

---

Thank you for helping improve weather-ml
