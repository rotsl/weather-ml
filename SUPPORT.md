# Support

Thank you for using weather-ml.

## Getting Help

If you need help:

1. Check the README
2. Review existing Issues
3. Search Discussions
4. Open a new Issue

---

## What to Include

When reporting problems:

- OS and Python version
- Logs / errors
- Steps to reproduce
- Screenshots (if applicable)
